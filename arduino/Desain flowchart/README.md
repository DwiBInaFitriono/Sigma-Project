# Bagan Metode Kegiatan — Project SIGMA

Folder ini berisi bagan urutan metode kegiatan pengerjaan Project SIGMA (Seismic Intelligent Ground-motion Monitoring & Alert).

## File

| File | Keterangan |
|------|------------|
| `bagan_metode_kegiatan.html` | Bagan dalam format HTML — buka di browser, lalu screenshot untuk laporan |
| `flowchart_metode_kegiatan_sigma.png` | Versi gambar PNG |

## Urutan Metode Kegiatan

```
Mulai
  ↓
Analisis Kebutuhan
  ↓
Desain Skematik (KiCad) & Cetak PCB
  ↓
Perakitan Perangkat Keras
  ↓
Pengembangan API Laravel & Web
  ↓
Pengembangan Aplikasi Flutter
  ↓
Pengujian Sistem
  ↓
Pembuatan Laporan
  ↓
Selesai
```

## Cara Pakai

1. Buka file `bagan_metode_kegiatan.html` di browser
2. Screenshot atau print sebagai PDF
3. Masukkan ke laporan
